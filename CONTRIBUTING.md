# Contributing

Thanks for taking a look.

## Issues

Open an issue on GitHub. Include what you expected, what happened, and the
smallest `company.md` pair that reproduces it.

## Pull requests

1. Fork the repo and create a branch from `main`.
2. Keep changes focused. One topic per pull request.
3. Make sure the examples in the README still produce the expected results.
4. Open a pull request against `main` and describe the change.
