# NDA Handshake One-Deal Exception

NDA Handshake Protocol, version 0.7

The person named in the exception block of a company's nda-handshake.md file gives this Exception on behalf of the company named in that file (the "Company"). Words defined in the NDA Handshake Confirmation (the "Confirmation") have the same meaning here.

1. **One agreement only.** This Exception applies to one mutual non-disclosure agreement: the agreement, if any, that the second round of the handshake identified in the exception block produces, with the counterparty to that handshake and for its stated purpose. It applies to nothing else.

2. **Wider positions.** For that agreement only, the Company accepts the positions stated in the exception block on the terms listed there, in place of the positions stated in the File on those terms. Each position in the exception block includes everything the File already accepts on that term. Every other position in the File applies unchanged.

3. **Approval.** The Company approves that agreement if the Protocol's result on the two parties' second-round files is AGREED, and executes it as set out in section 5 of the Confirmation. For that agreement, the Confirmation applies as if the positions in the exception block were stated in the File, and a term within those positions is treated as within the positions stated in the File.

4. **Second round.** A second round follows a first round that ended without agreement. It uses the same sealed exchange of invitation, offer, acceptance and check. It is open only for the terms on which the first round found no agreement. A party's second-round file is its first-round file with, at most, an exception block added. There is one second round and no further round.

5. **Authority.** The person giving this Exception represents that they have authority to bind the Company to this agreement on these terms and to give this approval. They need not be the person who gave the Confirmation.

6. **No standing change.** This Exception does not change the File, the Confirmation or the Company's positions for any other agreement. It ends when the second round ends, whether or not an agreement results.

7. **Signature and records.** The Company's signature on the agreement is applied as set out in the Confirmation, shown also with the name of the person who gave this Exception and its date. The Company will keep this Exception with the handshake record.

8. **Reliance and governing law.** A counterparty may rely on this Exception as it may rely on the Confirmation. This Exception is governed by the law that governs the Confirmation.
